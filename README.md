# Fast React Pizza Co.

Fast React Pizza Co. is a modern pizza ordering application built with React, Redux, and Vite. It allows users to browse a menu, add pizzas to their cart, and place orders with optional priority delivery. The app is designed with a clean and responsive UI, leveraging TailwindCSS for styling.

## Features

- **Menu Browsing**: View a list of pizzas with details like name, ingredients, price, and availability.
- **Cart Management**: Add, update, or remove pizzas from the cart.
- **Order Placement**: Place orders with customer details, phone number, and address.
- **Priority Orders**: Option to prioritize orders for faster delivery.
- **Order Tracking**: Search for and view order details, including estimated delivery time.
- **User Management**: Save and display the user's name and address using geolocation.
- **Responsive Design**: Optimized for both desktop and mobile devices.

## Tech Stack

- **Frontend**: React, React Router, Redux Toolkit
- **Styling**: TailwindCSS
- **Build Tool**: Vite
- **State Management**: Redux
- **API Integration**: Fetch-based services for menu, orders, and geocoding

## Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/abozaid01/Redux-Cart.git
   cd Redux-Cart
   ```

2. Install dependencies:

   ```sh
   npm install
   ```

3. Start the development server:

   ```sh
   npm run dev
   ```

4. Open the app in your browser at http://localhost:5173.

## API Endpoints

The app interacts with the following APIs:

- **Menu API:** Fetches the list of pizzas.
- **Order API:** Handles order creation, updates, and retrieval.
- **Geocoding API:** Fetches the user's address based on geolocation.
